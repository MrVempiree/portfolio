// 01 — about

Test. Verify. Report.

I'm a cybersecurity researcher and web pentester based in India, working remotely. My ground is the OWASP Top 10 — the flaws that hide in how browsers trust origins, how DNS records outlive the services they point at, and how input becomes code. CORS misconfigurations, subdomain takeover and XSS are where I spend most of my time.

When a manual check proves itself, I automate it. My flagship tools — cors-hunter and takeover-check — are zero-dependency Python, with the detection engines fully unit-tested offline and every verdict backed by evidence and a remediation. I also maintain web-security-labs and contribute to other researchers' projects, including a pull request adding CVE-2020-36170 to the wp-cve-hunter dataset.

  1. Map the trust boundaries first — origins, DNS, input points.
  2. Reproduce it, and capture the evidence — not just the claim.
  3. Automate the check into a tool with tests, so it never gets skipped.
  4. Report it so an engineer can act: impact, evidence, fix.

// 02 — the toolkit

    
Tools that prove it

    
Two flagship scanners lead the shelf — both zero-dependency Python, both fully unit-tested offline, both reporting evidence and remediation for every verdict. Authorised use only, always.

          CORS · browser trust
          33 tests
        
    
        
    cors-hunter
    
        
    A CORS misconfiguration scanner for authorised web security testing. Six targeted checks — arbitrary origin reflection, trusted null origins, wildcard-with-credentials, whole-subdomain trust, lookalike-domain trust and broken preflight handling — each finding explained with request/response evidence and a concrete fix. Terminal, JSON and Markdown reports, with CI-friendly exit codes.
    
        github.com/MrVempiree/cors-hunter ↗

  • 
        
    
          DNS · subdomain takeover
          33 tests · 15 fingerprints
        
    
        
    takeover-check
    
        
    A subdomain takeover fingerprint checker. It resolves CNAMEs, matches them against 15 well-known services — GitHub Pages, Heroku, S3, Azure, Netlify, Shopify and more — and classifies every subdomain as vulnerable, claimed or unknown, always with the evidence that produced the verdict. The tool never guesses.
    
        github.com/MrVempiree/takeover-check ↗
